
### 功能场景

咸鱼云网盘采用 **文件记录 + 文件物理存储** 的架构管理文件。正常情况下，每条文件记录都对应一份物理存储，用户通过文件记录访问文件。

当文件记录因意外丢失（如数据库异常、误操作等）时，对应的物理存储虽然仍然存在于磁盘上，但用户已无法通过网盘正常访问——这些"找不到归属"的物理存储即为 **失效数据**。反之，如果物理存储丢失而文件记录仍在，也会产生失效的文件记录。

**失效数据管理** 功能用于帮助管理员：

- **发现**系统中因记录与存储不一致而产生的失效数据
- **识别**失效文件的类型和内容（如图片宽高、视频时长、文档页数等），辅助判断文件价值
- **修复**可恢复的数据（RAW 模式下可自动重建文件记录）
- **处理**无法自动修复的数据——发布到认领广场供用户自行认领（UNIQUE 模式），或由管理员确认后丢弃

### 操作步骤与功能流程

#### 1. 检测失效数据

进入「失效数据管理」页面后，点击 **「开始检测」** 按钮发起扫描。系统将根据当前存储模式自动选择对应的识别策略：

| 存储模式 | 识别方式 |
|----------|----------|
| UNIQUE | 通过文件的唯一标识（哈希值）与文件记录进行比对，找出没有对应记录的物理存储 |
| RAW | 扫描所有物理存储，检查每个存储是否有对应的文件记录 |

检测以异步任务执行，完成后会在列表中展示所有失效数据记录。同一时间只能有一个检测任务在运行；重复检测时会清除上一轮「待处理」的记录，已处理完成的历史记录将被保留。

#### 2. 查看与筛选

检测完成后，管理员可以通过列表浏览所有失效数据，支持以下操作：

- **查看详情**：点击任意一行记录，右侧将弹出详情抽屉，展示基础信息、文件类型元数据、认领记录和文件预览（需先完成文件识别）
- **条件筛选**：按状态（待处理 / 已发布 / 已认领 / 已完成）、文件类型、文件大小范围进行筛选
- **排序**：按文件大小、创建时间等字段排序

#### 3. 文件类型识别

点击 **「识别文件类型」** 按钮，系统将对失效文件进行异步识别，提取文件的元数据信息，支持识别的类型包括：

| 文件类型 | 元数据示例 |
|----------|-----------|
| 图片 | 宽高、拍摄时间 |
| 视频 | 时长、分辨率 |
| 音频 | 时长、比特率、专辑名、歌手 |
| 文档 | 页数、作者 |
| 压缩/镜像文件 | 内含文件列表 |
| 文本文件 | 编码、行数、可能的编程语言 |

识别结果将显示在详情页的「类型信息」和「预览」页签中，帮助管理员判断文件内容和价值。

#### 4. 处理失效数据

根据存储模式不同，可选的处理操作有所差异：

**RAW 模式：**

- **一键修复 / 快速修复**：对可修复的失效数据执行自动修复，支持批量操作和全量修复。修复原理如下：
  - **失效文件记录**（文件记录仍在，但物理存储丢失）：检查物理存储是否存在，若存在且原路径可用则直接重建文件记录；若原路径不可用则修复失败；若物理存储已不存在，则尝试通过文件的 MD5 值在网盘已记录的文件中查找相同文件并复制，若仍未找到则修复失败
  - **失效物理存储**（物理存储仍在，但文件记录丢失）：直接为该存储重建文件记录，恢复文件访问路径和相关信息
- **丢弃**：对确认不需要的失效文件记录执行删除

**UNIQUE 模式：**

- **无法自动一键修复丢失的文件记录**：由于 UNIQUE 模式下，物理存储未冗余记录文件在网盘中的原始路径，只能依靠人工认领。
- **发布为可认领**：将失效物理存储发布到认领广场，允许用户自行认领
- **取消发布**：将已发布的失效数据撤回（前提：尚无认领记录）
- **认领**：指定文件名和保存路径，为物理存储重建一条文件记录（可多次认领）
- **标记处理完成**：关闭认领通道，标记为最终完成（前提：已有认领记录）
- **丢弃**：删除物理存储文件（前提：引用计数为 0 且未被认领）

**通用操作：**

- **下载**：在确认文件内容前，可先下载失效文件到本地查看
- **一键修复 / 丢弃全部**：对当前筛选结果中的所有记录执行批量操作

#### 5. 配置用户认领入口（UNIQUE 模式）

失效数据发布为可认领后，管理员还需配置用户端的访问入口，普通用户才能看到并认领数据：

1. 进入 **系统管理 → 桌面设置**
2. 在公共桌面中添加 **「失效数据认领」** 组件卡片
3. 保存设置

配置完成后，用户登录首页即可在公共桌面中看到「失效数据认领」卡片，浏览已发布的失效数据并进行认领：

1. 浏览已发布的失效数据列表，可查看文件类型和元数据信息
2. 选择要认领的记录，填写文件名和保存路径（公共网盘或我的网盘；只有管理员账号可以选择公共网盘）
3. 提交认领后，系统将创建一条新的文件记录指向该物理存储

### 注意事项

- **检测互斥**：同一时间只能运行一个检测或文件类型识别任务，需等待当前任务完成后才能发起新的检测
- **历史保留**：重复检测仅清除上一轮「待处理」状态的记录，「处理完成」的记录作为历史保留
- **UNIQUE 模式丢弃条件**：物理存储的引用计数必须为 0 且状态不为「已认领」才能丢弃
- **RAW 模式丢弃条件**：仅「待处理」状态的文件记录可被丢弃
- **取消发布条件**：仅在无认领记录时可取消发布
- **标记完成条件**：仅「已认领」状态的失效数据可标记为处理完成
- **认领权限**：未发布的失效数据仅管理员可操作；已发布的数据任何用户均可认领，但只能保存到自己的网盘（管理员无此限制）
- **RAW 模式不可用操作**：认领、发布为可认领、取消发布、标记处理完成等操作在 RAW 模式下不可用，该模式以自动修复为主
